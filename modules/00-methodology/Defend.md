# Defend - Module 00 (Threat Hunt Methodology)

## Defender Outcomes

Build a repeatable cloud hunting program that:

1. Defines hypothesis -> query -> validation -> action loops.
2. Converts successful hunts to detections and incidents.
3. Preserves evidence with bookmarks, notes, and entity context.

## Core Defensive Practices

- Maintain a minimum weekly hunt cadence for high-risk ATT&CK tactics.
- Use MITRE tactic/technique mapping to prioritize content gaps.
- Use result deltas and data-source health to identify blind spots early.
- Maintain a living backlog of hunts that become analytics rules or playbooks.

## Tooling Baseline

- Sentinel hunting queries
- Bookmarks and investigations
- Notebooks for repeatability and advanced analysis
