# Mitigate - Module 06 (Hardening Capstone)

## Capstone Mitigation Roadmap

## Phase 1 (Immediate)

- Contain active identity compromise paths.
- Remove unauthorized app/workload credentials.
- Lock down exposed data access channels.

## Phase 2 (Short Term)

- Implement missing Conditional Access and identity risk controls.
- Remediate over-privileged workload identities and RBAC assignments.
- Close critical telemetry gaps for all prior module scenarios.

## Phase 3 (Sustained)

- Convert capstone findings into tracked engineering standards.
- Run recurring validation hunts and purple-team style exercises.
- Measure MTTD/MTTR trend improvements across modules.
